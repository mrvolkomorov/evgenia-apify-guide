1. Установка за 4 шага

  1. Открыть страницу установки: hermes-agent.nousresearch.com/desktop
  2. Скачать файл под свою систему: для Windows — Hermes-Setup.exe, для macOS — Hermes-Setup.dmg
  3. Запустить двойным щелчком и дождаться. При первом запуске приложение само разворачивает локальную среду агента. Это занимает несколько минут и выглядит как скачивание компонентов. Окно не закрывать.
  4. Пройти мастер настройки. Если система спросит разрешение на запуск — разрешить, без этого агент не сможет работать с файлами.
Если установщик не запускается Проверить свободное место на диске. Если блокирует антивирус — это ложное срабатывание на локальную среду агента, нужно добавить папку в исключения.

2. Модель: три способа подключить

Главное, что нужно понять про устройство: агент — это оболочка, модель — то, что внутри отвечает. Подключаются они отдельно.

СпособЧто делатьКому подходит
A. Портал-провайдерОдна подписка сразу даёт: модель, поиск в сети, генерацию картинок, озвучку и браузер. Ничего настраивать не нужно.Самый быстрый путь
B. MiniMax через браузерВход без ключа и без зарубежной карты.Когда карты нет
C. Свой провайдерНапример OpenRouter: ключ вставляется в настройках, раздел «Провайдеры».Если провайдер уже оплачен

Где переключать модель в процессе работы: прямо рядом с полем ввода, слева от микрофона. Модель по умолчанию для всех новых чатов задаётся в настройках, раздел «Модель», строка «Основная модель».

Проверка подключения Задать агенту вопрос: «Ответь одним предложением, что ты умеешь». Ответ получен — модель работает.

3. Агенты: где это в интерфейсе

Вкладка Bots в левой панели, рядом со списком разговоров. Внутри — реестр агентов: у каждого своя иконка, свой отдельный чат и свои регулярные задачи.

  1. В реестре нажать создание нового агента.
  2. Заполнить имя и описание.
  3. Раскрыть блок дополнительных настроек. В нём задаются: модель, личность, навыки, наборы инструментов и подключённые коннекторы.
Главное отличие от обычного чата Инструкция пишется один раз и живёт в агенте. Все его ответы собираются вокруг этой инструкции, а не вокруг каждого нового запроса.

Готовые тексты инструкций — Раздатка 2.

4. Коннекторы: как подключить внешний сервис

Коннектор даёт агенту доступ к сервису, которого у него нет. Схема всегда одна: адрес сервиса плюс вход.

Где настраивается: настройки, раздел «MCP-серверы». Там же есть встроенный каталог готовых подключений.

Вход бывает двух видов:

  • через браузер — агент показывает ссылку, вход подтверждается в браузере;
  • по токену — ключ вставляется в поле.

Готовый пример — Apify

  • адрес сервиса: https://mcp.apify.com/
  • токен берётся в Apify: раздел «Настройки», затем «Интеграции»;
  • второй путь, короче: поставить плагин Apify из каталога, см. раздел 5.

Если коннектор добавлен, а новых инструментов в чате не видно — ввести в чате команду /reload-mcp.

5. Плагины: где расширяется агент

Раздел Capabilities, вкладка Plugins. Это единственное место, где агент расширяется. Одна строка на плагин и два выключателя:

КолонкаЧто расширяет
Desktopприложение: панели, кнопки, темы
Agentсамого агента: новые инструменты, новые модели

Два способа установки:

  • Из каталога — проверенные записи, закреплённые на конкретной версии кода.
  • Install from Git — любой репозиторий по адресу.
Что важно понимать про второй способ Код из каталога проверен людьми, код по адресу — нет. Плагин для настольного приложения выполняется с правами самого приложения и не изолирован в отдельной среде. Поэтому ставится только то, что прочитано и понято.

6. Apify: аккаунт и тариф

Кабинет: https://console.apify.com/

Тариф бесплатный 5 долларов в месяц на запуск сценариев. Банковская карта для регистрации не нужна. Неиспользованный остаток сгорает в конце месяца и не переносится.

Где смотреть остаток: в кабинете, раздел Billing.

7. Replicate: как получить ключ

Кабинет и ключи: https://replicate.com/account/api-tokens

Ключ создаётся в личном кабинете и начинается с символов r8_.

Правило безопасности Ключ работает как пароль. Не пересылать его в чатах и не показывать на экране при трансляции.

Куда вставляется: ключи хранятся в файле настроек агента, а не в переписке. Путь к папке агента:

  • Windows: %LOCALAPPDATA%\hermes
  • macOS и Linux: ~/.hermes

Файл с ключами называется .env и лежит в этой папке.

8. Чек-лист занятия

  • Приложение установлено и запускается
  • Модель подключена, агент отвечает
  • Созданы два агента с инструкциями
  • Запрет в инструкции работает, агент не выдумывает данные
  • Apify подключён, есть выгрузка в таблице
  • Плагин правки изображений установлен
  • Ключ Replicate получен, первая правка сделана

9. Если не получилось

Агент не отвечает после подключения моделиНачать новый чат, в чате должен появиться выбор модели
В реестре агентов пустоВкладка Bots находится рядом со списком разговоров в левой панели
Коннектор подключён, инструментов нетВвести в чате /reload-mcp
Apify не пускаетБесплатный тариф карту не требует, зарегистрироваться заново
Ключ Replicate не создаётсяНужна зарубежная карта: aifory pro, Wise или Revolut
